# AI-Agent-Qa 示例文档

这是一份用于测试上传文档问答功能的 Markdown 示例文档。

## 核心内容

AI-Agent-Qa 是一个基于 RAG 的文档问答系统。系统支持上传 PDF、Word、TXT、Markdown 文档，自动进行文本解析、文本分块、TF-IDF 向量化和余弦相似度检索。

## 技术路线

用户上传文档后，系统首先解析文本，然后按固定长度切分为多个文本块。之后，系统使用 TF-IDF 将文本块转换为向量，再用余弦相似度检索与用户问题最相关的片段，最后调用 DeepSeek 生成回答。

## 项目亮点

1. 支持多格式文档上传。
2. 回答结果展示来源片段和相似度。
3. 集成机器学习文本分类模型。
4. 可部署为公开访问的 Web 应用。
