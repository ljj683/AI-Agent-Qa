# Dify 智能体搭建指南

## 一、Dify 的定位

Dify 是本项目的平台化智能体展示入口，主要用于展示：

- 知识库构建
- RAG 检索增强
- 文档提取器
- 提示词工程
- 智能体发布链接

完整的 TF-IDF 分块检索、余弦相似度和模型评估主要在 Streamlit 自研系统中实现。

## 二、知识库问答智能体

流程：

```text
用户输入 -> 知识检索 -> LLM -> 直接回复
```

### LLM SYSTEM 提示词

```text
你是一个专业、严谨、现代化的文档问答 AI 智能体，主要基于知识库内容回答用户问题。

回答要求：
1. 必须优先依据知识库检索结果回答；
2. 如果知识库中没有明确依据，请说明“知识库中没有找到明确依据”，不要编造；
3. 先给结论，再分点解释；
4. 回答要结构清晰，适合学生理解；
5. 回答结尾写：参考依据：知识库检索结果。

用户问题：
{{#sys.query#}}

知识库检索结果：
{{#context#}}
```

如果 `{{#context#}}` 不生效，请用 Dify 变量选择器插入上下文变量。

## 三、上传文档问答智能体

建议新建一个应用：

```text
基于 RAG 的上传文档问答 AI 智能体
```

流程：

```text
用户输入 + 文件上传 -> 文档提取器 -> LLM -> 直接回复
```

### 欢迎语

```text
你好，我是上传文档问答 AI 智能体。请上传一份 PDF、Word、TXT 或 Markdown 文档，然后向我提问。我会根据上传文档内容进行总结、解释和问答。如果文档中没有明确依据，我会如实说明。
```

### 开场问题

```text
请总结这份文档的主要内容
这份文档的核心观点是什么？
请提取这份文档的三个重点
这份文档中和机器学习相关的内容有哪些？
```

### LLM SYSTEM 提示词

```text
你是一个专业、严谨的上传文档问答 AI 智能体。

用户会上传 PDF、Word、TXT 或 Markdown 文档，并提出问题。你需要根据文档提取器输出的内容回答用户问题。

回答要求：
1. 优先依据上传文档解析内容回答；
2. 如果上传文档中没有明确依据，请说明“上传文档中没有找到明确依据”，不要编造；
3. 先给出简洁结论，再分点解释；
4. 回答要适合课堂展示，结构清晰，不要过长；
5. 回答结尾写：参考依据：用户上传文档解析内容。

用户问题：
{{#sys.query#}}

上传文档解析内容：
{{#文档提取器输出变量#}}
```

最后一行变量不要硬打，用 Dify 变量选择器插入文档提取器输出。
